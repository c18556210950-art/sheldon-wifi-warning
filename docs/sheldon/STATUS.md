# 开发状态

截至 2026-11-26，本项目已按发布者要求暂停手机端开发，仅整理公开源码。

已完成 Android 共享警告原型、APK 构建与测试机安装，以及主机端门户和 TCP 流程测试。Shizuku 测试网络相关权限、接口和 TUN 创建曾在 Redmi Turbo 3 / Android 16 上验证。

未完成真实访客自动弹页、录音播放、网络恢复、重连和多设备验收；不能宣称成品已可用。用户接受共享状态，不再要求逐设备白名单或独立放行。

未开发 iOS 版本。基于公开 API，iPhone 个人热点没有提供部署这种认证门户所需的控制接口。

公开录音由发布者明确要求保留。仓库不包含本地安装包、签名密钥、个人网络地址、手机序列号或构建缓存。
